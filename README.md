# Data Storytelling using Python

## Project Description

This project focuses on analyzing sales performance data using Python and transforming raw business data into meaningful insights through data storytelling techniques.

The dataset contains information related to:
- Sales revenue
- Orders
- Product categories
- Regions
- Discounts
- Monthly and quarterly performance

The main objective of this project is to understand business trends, identify high-performing categories and regions, and analyze how discounts affect overall revenue.

Using Python libraries such as Pandas, NumPy, SciPy, Matplotlib, and Seaborn, the project performs:
- Data cleaning
- Feature engineering
- Statistical analysis
- Correlation analysis
- Trend analysis
- Data visualization

The project also generates multiple visualizations including:
- Monthly revenue trends
- Category-wise revenue comparison
- Regional revenue share
- Quarterly growth analysis
- Correlation heatmaps
- Orders vs Revenue analysis

## Key Insights

- Electronics category generated the highest revenue throughout the year.
- The North region contributed the largest share of total revenue.
- Q4 showed the strongest sales growth compared to other quarters.
- Higher discounts did not significantly increase revenue.
- August was identified as the weakest sales month.
